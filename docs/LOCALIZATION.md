# German and English / Deutsch und Englisch

All new user-facing interface text must ship in German and English. Keep setup/options, service metadata and entity translations in `strings.json` (English source), `translations/en.json` and `translations/de.json` in sync. The admin panel and card share the `RN_TRANSLATIONS` catalog in `reliable-notify-card.js`; use `rnTranslate` / `this.t()` at UI boundaries. Language comes from the HA profile, with English as the fallback. Add a UI test for new controls in both languages. Never translate stored aliases, entity IDs, service names, message bodies, secrets or YAML/API keys. Provider errors and raw diagnostics may retain their original text.

Neue Oberflächentexte müssen immer auf Deutsch und Englisch vorliegen. Einrichtung, Optionen, Aktionsbeschreibungen und Entitätsübersetzungen in `strings.json` (englische Quelle), `translations/en.json` und `translations/de.json` synchron halten. Panel und Karte verwenden gemeinsam `RN_TRANSLATIONS` in `reliable-notify-card.js`; UI-Texte über `rnTranslate` / `this.t()` ausgeben. Die HA-Profilsprache bestimmt die Sprache, Englisch dient als Rückfall. Neue Bedienelemente in beiden Sprachen testen. Gespeicherte Zielnamen, Entitäts-IDs, Aktionsnamen, Nachrichtentexte, Zugangsdaten und YAML-/API-Schlüssel niemals übersetzen. Fehler externer Dienste und technische Diagnosedaten können im Originaltext bleiben.
