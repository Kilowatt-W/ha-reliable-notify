# Reliable Notify v3.8.5

## Deutsch
Übersichtlichere Ansicht „Ziele & Personen“:
- **Gruppeninhalt sichtbar:** Unter jeder Gruppe steht jetzt, welche Ziele sie enthält, z. B. „Enthält: TriCorder, BerniPhone, TriCorderTab, Walltablet“.
- **Hilfe als „?“:** Der große Block „Hilfe zu diesem Bereich“ ist in diesem Bereich durch einen runden „?“-Knopf direkt hinter dem Einleitungstext ersetzt. Ein Klick klappt die vollständige Hilfe darunter auf; „Hilfe einblenden/ausblenden“ oben wirkt weiterhin.

## English
A clearer “Targets & people” view:
- **Group members visible:** each group now shows the targets it contains, e.g. “Contains: TriCorder, BerniPhone, TriCorderTab, Walltablet”.
- **Help as “?”:** in this section the large “Help for this section” block is replaced by a round “?” button right after the intro text. Clicking it opens the full help below; “Show help / Hide help” at the top still works.
